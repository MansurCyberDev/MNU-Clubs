# MNU Community — аудит кнопок и пользовательских действий

Проверка выполнена для статического MVP. Все основные элементы ведут к экрану, выполняют действие или открывают понятный демо-ответ; пустые `#`-ссылки убраны. Сохранение данных пока локальное для текущего браузера.

| Область | Контролы и результат |
|---|---|
| Навигация | Главная, каталог, заявки, мои организации, создание организации и подбор переключают соответствующие экраны. Логотип возвращает на главную. Личные экраны сначала открывают форму входа. |
| Каталог | Карточки и кнопки открывают профиль организации; поиск фильтрует список; чипы фильтруют по направлению. Заявку можно начать обеими кнопками на экране организации. |
| Профориентация | Четыре открытых вопроса показывают результаты сопоставления по темам ответов. Интересы из профиля также учитываются. Подбор демонстрационный, без подключённой AI-модели. |
| Регистрация и профиль | Создание аккаунта, вход, проверка пароля, сохранение имени/курса/интересов/настроек уведомлений и выход работают в этом браузере. Незнакомая почта/пароль дают ошибку, а не пустой экран. |
| Заявки | Контактные данные сохраняются в профиле браузера; статус переводится на этап отбора; отдельное явно помеченное демо-действие имитирует одобрение организации. Только после него профиль показывает членство. |
| Моя организация | Если членства нет, показывается переход в каталог. Для AI Club доступны вкладки обзора, событий, фотоархива, объявлений и контактов. Запись на событие меняет кнопку и появляется в уведомлениях. |
| Фотоархив | Две карточки используют включённые изображения. У обеих есть ссылка скачивания с заданным именем файла. |
| Создание организации | «Продолжить» проверяет обязательные поля и переводит между тремя шагами; «Назад» возвращает к предыдущему; отправка показывает и сохраняет статус на рассмотрении; черновик можно открыть повторно после навигации/обновления. |
| Уведомления и справка | Колокольчик показывает заявки/записи либо объясняет, что уведомлений пока нет; справка открывается отдельным окном и ведёт в каталог. Закрытие окна и переход работают. |
| Обратная связь и контакты | Отзыв проходит проверку и сохраняется как демо-обращение в браузере. Почта открывает `mailto:`. У Telegram заменён нерабочий пустой адрес на объяснение, что в примере реальный канал не подключён. Ссылка координатора показывает демо-подсказку. |

## Что потребуется для полноценной эксплуатации

- Серверная аутентификация с подтверждением университетской личности, восстановлением доступа и защитой сессий.
- Серверная база данных и проверка прав для заявок, членства, организаций и административных решений.
- Реальный канал отправки заявок/обратной связи, уведомлений и ссылок организаций.
- Хранилище фотографий и управление альбомами организаторами.
- Проверенные MNU правила доступа, домены почты, контактные данные и контент. Сейчас указанные в интерфейсе организации и показатели — демонстрационные.

Проверены в браузере: регистрация тестового аккаунта, повторный вход после выхода, изменение настроек профиля, переход из каталога к заявке, первый и второй этапы заявки, демо-подтверждение членства, страница AI Club, записи на мероприятие, список уведомлений и наличие двух кнопок скачивания.
