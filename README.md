# MNU Clubs

Статический MVP-проект для каталога студенческих организаций MNU.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в корне репозитория. Сборка и установка зависимостей не требуются.

## Развёртывание

Опубликуйте корень репозитория как статический сайт. Файлы `index.html`, `app.js`, `styles.css` и папка `assets/` должны оставаться рядом.

## Ограничения демо

Это браузерный прототип: аккаунты и данные хранятся локально в браузере и не синхронизируются с сервером. Вход не подтверждает статус студента. Перед реальным запуском подключите одобренную университетскую авторизацию, серверные сессии, базу данных и управляемое хранилище фотографий. Не используйте реальные университетские пароли с демо.
